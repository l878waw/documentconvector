HOW TO USE THE WEB APP:
-----------------------

1. Click "Upload" tab
2. Click to upload your file (PDF, HTML, DOCX, TXT)
3. Choose a style (modern, classic, minimalist, bold)
4. Click "✨ Generate"
5. Download your image!

TWO WAYS TO START WEB APP:
---------------------------

METHOD 1: Script (Easiest!)
  👆 Run: ./launch_webapp.sh
  ✅ Browser opens automatically at http://localhost:8000

METHOD 2: Terminal
  cd /path/to/documentconvector
  python3 webapp.py

Then open: http://localhost:8000

ACCESS FROM PHONE/TABLET:
--------------------------

1. Make sure your computer and phone are on same WiFi
2. On your phone browser, go to:
   http://YOUR_IP_ADDRESS:8000

   (Check the terminal output for your IP address)

TROUBLESHOOTING:
----------------

"Can't connect to server"
→ Make sure you started it first!
→ Run: ./launch_webapp.sh or python3 webapp.py

"Port already in use"
→ Another app is using port 8000
→ Try closing other apps or restart

"Page not found"
→ Check the URL: http://localhost:8000
→ Make sure server is running (check terminal output)
