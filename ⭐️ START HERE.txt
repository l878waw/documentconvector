⭐️ START HERE - SIMPLEST WAY
==================================================

🎯 TWO WAYS TO START:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 1: DOUBLE-CLICK (EASIEST!)
----------------------------------

1. Find and double-click:
   START_NOW.sh

2. Follow the prompts:
   - Drag your PDF/HTML/TXT/DOCX file
   - Choose format (png/jpg/jpeg/pdf)
   - Choose style (modern/classic/minimalist/bold)

3. Done! File is converted!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 2: TERMINAL (FASTEST!)
------------------------------

1. Open Terminal

2. Navigate to the documentconvector directory:
   cd /path/to/documentconvector

3. Convert your file:
   python3 convert.py /path/to/your/document.pdf png modern

DONE! ✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

QUICK EXAMPLES:
---------------

# Modern style PNG:
python3 convert.py document.pdf png modern

# Classic style JPG:
python3 convert.py document.pdf jpg classic

# Bold style JPEG:
python3 convert.py document.pdf jpeg bold

# Minimalist PDF:
python3 convert.py document.pdf pdf minimalist
